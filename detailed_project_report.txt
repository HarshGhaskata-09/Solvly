1. PROJECT OVERVIEW
================================================================================

Solvly is an advanced mathematical problem-solving Android application designed 
for students, teachers, and lifelong learners. It provides instant, 
step-by-step solutions to mathematical problems. The app supports three input 
modes:

    • Text Input (Typed Math)
    • Camera Capture
    • Gallery Image Selection

Key Features Include:

    • AI-powered solver using Google Gemini 2.0 Flash (via direct REST API)
    • Offline local math solver engine (for basic to intermediate problems)
    • OCR text recognition (Google ML Kit Text Recognition)
    • Image cropping before processing
    • Problem history with date headers, auto-delete options)
    • History search filtering, copy, share)
    • Theme support (System default / Light / Dark)
    • Notification reminders & Notifications)
    • Bug reporting with image attachments)
    • Cache management)
    • Privacy Policy, License & About screens)
    • Data encryption info screen

Static API_KEYS: loaded comma-separated list of keys from BuildConfig (from local.properties) rotating on HTTP 429/403/400).

PUBLIC API: solveAsync(String rawText, byte[] imageData, String mimeType, AISolverCallback callback)

FAST PATH CHECK:
  if normalizedText not empty <100 chars → try local MathSolver first.
  if localResult.isSuccess → immediate return success.

GEMINI REST API CALL Thread):
  Endpoint POST https://generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash:generateContent?key={apiKey}
  Timeouts: connect=10s, read=20s.
  Request Body JSON:
    contents: [{ parts: [
      { text: prompt },
      { inline_data: { mime_type, data: base64(imageData) } }
    ] }]

Prompt: "You are an expert math solver. Solve ONLY ONE mathematical problemReturn ONLY as JSON ARRAY with ONE object with keys:
  • problem_title
  • cleaned_problem
  • final_answer
  • steps: array of strings

RESPONSE PARSING:
  extract candidates[0].content.parts[0].text
  remove ```json ``` markers
  parse JSON array or single JSON object
  ONE result only (first element results.get(0)) used.)

FALLBACK:
  If API call failed → handleOfflineFallback MathSolver offline solver.
  If offline solver fails → error with original error message + "Please connect internet".

5.3 MathSolver (d:\Solvly\app\src\main\java\com\example\solvly\utils\MathSolver.java)
────────────────────────────────────────────────────────────────────────────────
OFFLINE local mathematical engine regex parsers in order:
  SolveResult data class: title, scannedText, answer, List<String> steps, boolean isSuccess, errorMessage

Solve order:
  1. solveUnitConversion: regex "10m to cm", etc. Conversions: m↔cm, km↔m, kg↔g, l↔ml (limited set)
  2. solveQuadratic: ax² ± bx ± c = 0 → discriminant method quadratic formula)
  3. solveSimultaneous: ax+by=c, dx+ey=f → Cramer's Rule 2x2 system.
  4. solveLinearEquation: 3 formats:
       • ax ± b = c
       • b ± ax = c
       • ax = c
       Supports fractions like x/2 = 5
  5. solveCalculus: d/dx(ax^n differentiation) and ∫ax^n dx integration power rules
  6. solveScientific: sqrt, sin/cos/tan DEGREES→radians, a^b exponents
  7. solveBasicArithmetic → ExpressionEvaluator recursive descent PEMDAS
ExpressionEvaluator private nested class:
    • parseExpression add/subtract
    • parseTerm multiply/divide
    • parseFactor parentheses/numbers/exponentiation

Normalization:
    • lowercase, strip whitespace to single
    • OCR fix l→1 i→1 o→0 (only if no sqrt/sin/cos/tan)

formatResult: integer if whole else trimmed trailing zeros.
